# Productivity

General workflow tools, not code-specific.

- **[caveman](./caveman/SKILL.md)** — Ultra-compressed communication mode. Cuts token usage ~75% by dropping filler while keeping full technical accuracy.
- **[grill-me](./grill-me/SKILL.md)** — Get relentlessly interviewed about a plan or design until every branch of the decision tree is resolved.
- **[help](./help/SKILL.md)** — Explain the idd workflow, route to the next skill, and clarify `/clear` boundaries.
- **[write-a-skill](./write-a-skill/SKILL.md)** — Create new skills with proper structure, progressive disclosure, and bundled resources.
- **[teach](./teach/SKILL.md)** — Teach a new skill or concept across multiple sessions, keeping a glossary and learning record in the workspace.
- **[handoff](./handoff/SKILL.md)** — Compact the current conversation into a handoff document so a fresh agent can pick up the work.
